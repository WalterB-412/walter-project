## 1. 01_자동화/네이버_블로그/경제 / 01_자동화/네이버_블로그/리빙

**목적:** Claude로 생성한 경제/리빙 블로그 포스팅을 Playwright로 네이버 블로그에 자동 발행

**아키텍처:**
- `서버시작_v2.py` (경제) / `서버시작.py` (리빙): Python HTTP 서버 2개 동시 실행
  - 포트 8080: 웹 UI 서버 (폴더 내 버전 번호 가장 높은 `.html` 파일 자동 선택)
  - 포트 8766: 프록시 서버 (HTML ↔ Playwright 브릿지, OAuth 콜백 처리)
- `네이버_블로그_자동화_*.html`: 사용자 UI (Claude API 호출 → 글 생성 → 발행 트리거)
- `user_data.json`: 블로그 ID 등 사용자 설정 영구 저장 (HTML 버전과 무관하게 유지)

**실행:**
```bash
# 경제 블로그
cd "/Users/kakao/Documents/2. 개인/Walter Project/01_자동화/네이버_블로그/경제"
python3 서버시작_v2.py
# → http://localhost:8080 자동 열림

# 리빙 블로그
cd "/Users/kakao/Documents/2. 개인/Walter Project/01_자동화/네이버_블로그/리빙"
python3 서버시작.py
```

**.command 파일로도 실행 가능 (더블클릭):**
- `블로그자동화_시작.command` (경제)
- `네이버_블로그_리빙_시작.command` (리빙)

**의존성:**
```bash
pip install playwright playwright-stealth
playwright install chromium
```

**핵심 주의사항:**
- `서버시작_v2.py` 수정 후 반드시 서버 재시작 (코드 1회만 로드됨)
- Playwright는 `.naver_profile/` 디렉토리에 Chromium 프로필을 영구 저장 (로그인 세션 유지)
- 표 삽입: SE ONE 에디터 툴바 버튼 클릭 → JS로 행/열 조정 → 셀 직접 타이핑 방식
- 디버그 로그: `pw_debug.log`, 스크린샷: `pw_screenshots/`

## 2. 01_자동화/크롬확장_경제

**목적:** Google Trends KR 실시간 키워드 분석 + 네이버 데이터랩 교차 검증 → 블로그 자동화 원클릭 전송

**아키텍처:** Manifest V3 Chrome Extension
- `manifest.json`: sidePanel + background service worker
- `background.js`: 메시지 라우팅, API 호출
- `sidepanel.html` + `sidepanel.js`: UI (트렌드 키워드 표시, 블로그 자동화 연동)
- `localhost:8766` (프록시 서버)에 POST 요청으로 블로그 자동화 트리거

**설치 (개발자 모드):**
1. `chrome://extensions` → 개발자 모드 ON
2. "압축해제된 확장 프로그램 로드" → `01_자동화/크롬확장_경제/` 선택

**수정 후 적용:** 확장 프로그램 페이지에서 새로고침 버튼 클릭

## 4. 01_자동화/카드뉴스_자동화

**목적:** 경제/재테크 주제 카드뉴스 HTML → Puppeteer로 PNG 캡처

**실행:**
```bash
cd "/Users/kakao/Documents/2. 개인/Walter Project/01_자동화/카드뉴스_자동화"
CARDCAP=$(ls capture_v*.mjs 2>/dev/null | sort -V | tail -1)   # 최고 버전 자동 선택 (v1.1+ = 2배율 캡처)
node "${CARDCAP:-capture.mjs}" "/Users/kakao/Documents/2. 개인/Walter Project/02_콘텐츠/경제/NNN_YYYYMMDD_키워드"
```

**결과물 저장 위치:**
- 경제: `02_콘텐츠/경제/NNN_YYYYMMDD_키워드/`
- 테크: `02_콘텐츠/테크/NNN_YYYYMMDD_키워드/`

> ⚠️ 경로를 직접 지정하므로, 실행 시 경제/테크 서브폴더 경로를 인자로 전달.
> capture_v1.1+는 2배율(2160²) 렌더 후 ffmpeg lanczos로 1080² 다운스케일 (텍스트 선명도↑, ffmpeg 필요).

## 5. 01_자동화/숏폼_자동화

**목적:** 세로 숏폼(1080×1920) 영상 자동 생성 — scenes.json → HTML 렌더 → PNG → TTS → FFmpeg mp4

**실행:**
```bash
cd "/Users/kakao/Documents/2. 개인/Walter Project/01_자동화/숏폼_자동화"
```

> ⚠️ 실행 시 `--out` 인자로 저장 폴더 직접 지정:

## 9. 01_자동화/유튜브_텍스트추출

**목적:** 유튜브 숏츠(일반 영상 포함) URL → 텍스트 추출. 자막 있으면 자막, 없으면 오디오 추출 후 Whisper STT로 전사.

**실행 (Claude 스킬 `/숏츠텍스트추출`로도 호출 가능):**
```bash
cd "/Users/kakao/Documents/2. 개인/Walter Project/01_자동화/유튜브_텍스트추출"
SCRIPT=$(ls extract_text_v*.py | sort -V | tail -1)   # 최고 버전 자동 선택
python3 "$SCRIPT" "<유튜브 URL>" [--lang ko] [--model small] [--out 저장폴더]
```

**결과물:** `output/<video_id>/transcript.txt` (제목·채널·출처·URL 헤더 + 본문)

**의존성:**
```bash
pip3 install yt-dlp certifi openai-whisper
brew install ffmpeg
```

> ⚠️ Whisper STT는 자동 전사이므로 고유명사·숫자 오인식 가능 — 콘텐츠 소스로 재활용 전 사람 검수 권장.
