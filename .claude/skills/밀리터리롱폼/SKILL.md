## 세션 4분할 ★토큰 절감 핵심

비용은 세션 길이의 **제곱**에 비례한다(실측 4.2배 차이). **롱폼은 씬이 30~70개로 숏폼의 3~4배라 분할 효과가 숏폼보다 크다.** 상태는 전부 `_work/millong_NNN/` 파일에 있으므로 끊어도 잃는 게 없다.

| 세션 | 담당 STEP | 완료 조건 | 모델 |
|---|---|---|---|
| **S1 기획** | 0 팩트(출처 등급) · 0.5 소재 가용성 · 1 대본 · 1.5 정보 그래픽 렌더 | `scenes.json` + `facts.json`(v2) + `graphics/` + **예상 길이 9~11분** | Opus 필수 |
| **S2 수집** | 2 풋티지 수집 (+AI컷 반입) | `manifest.json` | Opus/Sonnet |
| **S3 검수** | 3 눈검수 · 4 TTS | `tts/` | **Opus 필수** (비전 판별) |
| **S4 출고** | 5 preflight · 6 빌드 · postflight · 썸네일 · 7 챕터·캡션 | mp4 + caption | Opus |

**모델 확인 ★세션 첫 응답**
세션 단계가 정해지면(신규=S1, 이어서=handoff 결과) 현재 모델(시스템 프롬프트의 모델명)을 위 표 '모델' 열과 대조한다.
- **일치하면 아무 말도 하지 않는다.**
- 불일치면 첫 응답 맨 위에 한 줄: `⚠️ 모델: 현재 Sonnet — 이 세션(S3 검수)은 Opus 필수`
- **"필수" 세션이면 Walter 답을 받은 뒤 진행**한다. 그 외(Opus/Sonnet·Opus 권장)는 알리고 바로 진행.
- 세션 도중 모델이 바뀐 게 보이면 다시 대조한다.

**세션 운영**
- **세션 경계는 승인 게이트가 아니다.** 담당 STEP을 끝내면 handoff를 만들고 **그냥 세션을 끝낸다.**
- **S3는 씬이 많으면 더 쪼갠다** — 30씬 초과면 챕터 단위로 S3a(챕터 1~3)/S3b(챕터 4~6). 눈검수 시트 이미지가 최대 토큰 싱크다.
- **눈검수 시트 이미지는 S3에서만 연다.**
- STEP 1.5 그래픽이 없으면 STEP 2가 graphic 씬을 등재하지 못한다 — S1에서 반드시 끝낸다.
- 세션 인계(세션 종료 직전 + 새 세션 시작 직후):
  ```bash
  python3 "$(ls handoff_v*.py|sort -V|tail -1)" --run NNN
  ```
  진행 단계를 파일 존재로 판정 + 예상 길이(TTS 전 글자수 추정 / 후 mp3 실측)를 `handoff.md`와 stdout으로 출력. **상태파일 전량을 읽지 말고 handoff가 가리키는 파일만 연다.**
- 다음 세션 진입: `/밀리터리롱폼 이어서 NNN` → 첫 동작은 위 handoff 실행.

## 구조 — 영상 전체가 하나의 큰 6비트

숏폼 6비트를 5~6번 반복하는 게 **아니다.** 전체가 큰 6비트이고, 챕터 각각이 그 안의 미니 이야기다.

```
콜드오픈 (HOOK, 사건 한복판)
  → ★인사(GREETING)  ← 위치 고정
  → 챕터 1   [기] 왜 이 주제인가 — 오픈 루프 투척
  → 챕터 2~3 [승] 상황이 쌓인다 (각 챕터가 위기→반전→증거의 미니 아크)
  → 챕터 4~5 [전] 판이 뒤집히는 지점 — 가장 아껴둔 사실/숫자
  → 챕터 6   [결] 그래서 지금 무엇이 달라졌나
결론 (CTA, 콜드오픈 콜백 + "그래서 무엇이 바뀌었나" + 열린 질문 1개)   ← 애국 CTA 폐지
```

**다큐 톤 (스타일가이드 §0-D)** — 형용사 대신 날짜·장소·사람·숫자. 국뽕·선정 표현은 preflight `[HYPE]`가 차단
(압도적·세계가 놀란·경악 등). 적을 조롱하지 않는다. **한계·반론·비용을 다루는 씬 필수**(`counterpoint: true`).
숏폼의 심리 엔진·자극 장치·단정형 훅은 롱폼에 쓰지 않는다.

**챕터↔챕터 사이에도 연결(전환 커넥터·오픈루프)이 있어야 한다.** 챕터가 바뀐다고 이야기가 리셋되면 안 된다.

### 인사 씬 (GREETING) — 모든 롱폼 공통

```json
{"id": 4, "beat": "GREETING",
 "text": "안녕하세요. 대한의 밀리터리 입니다.",
 "footage": {"weapon": "<이 편의 주력 무기 슬러그>", "prefer": "video"}}
```

- **첫 문장은 토씨까지 고정** — preflight가 대조한다. 뒤에 그 편만의 인사말을 붙이는 건 자유.
- **위치는 콜드오픈 직후 고정.** 맨 앞이면 첫 3초를 인사에 써서 훅이 죽고, 챕터1 뒤면 본론 도입을 끊는다.
- `chapter_title`을 달지 마라(챕터는 그다음 씬부터). `why`·`fact_ids` 대상이 아니다.
- **화면은 반드시 붙인다** — 주력 무기 중 가장 그림 좋은 컷(빈 화면 금지).
- 인사를 빼고 읽었을 때 콜드오픈 → 챕터1이 자연스럽게 이어지면 합격.

### 챕터 서사 역할 (arc)

```json
{"id": 21, "beat": "PROOF", "text": "...", "why": "...",
 "chapter_title": {"num": "CHAPTER 04", "line1": "독일이 진 날", "line2": "가격표가 갈랐다", "arc": "전"}}
```

- 소제목 표시: line1 = 질문·장면(굵게 ≤20자), line2 = 사실 정보(기울임 ≤28자: 사건명·날짜·장소).
  챕터 첫 씬 앞 **3초 무나레이션**으로 좌측 하단에 뜬다(총 길이에 포함, 6챕터 ≈ +18초). 그 3초 화면은 실사 롱테이크로.
- 값은 **기 / 승 / 전 / 결** 4개뿐 (오타는 preflight가 exit 1)
- 한 역할이 여러 챕터에 걸쳐도 된다(승 2~3개가 정상). 단 **순서는 기→승→전→결** — 역행하면 `[ARC-ORDER]`
- **`전`은 반드시 하나 지정한다.** 없으면 `[NO-TURN]` — 판이 뒤집히는 지점이 없다는 뜻이고 그게 중반 이탈의 원인이다. `전` 챕터에 **가장 아껴둔 팩트**를 배치한다.
- ⛔ **시간을 배분하지 마라.** "[승]은 1:30~4:00" 식으로 정하면 대본이 시간표를 채우려 늘어진다. arc는 **순서와 역할**만 정하고 길이는 결과다.
- 챕터 3개면 `기/전/결`(승 생략)도 유효 — 4개를 억지로 채우지 마라.
- **챕터 최소 3개** (유튜브 챕터 기능 하한, 각 10초 이상, 설명 첫 줄 `0:00` 필수). 2개 이하면 챕터가 안 잡혀 탐색성·미드롤 자연 지점이 둘 다 사라진다. → `[NO-CHAPTERS]`
- 챕터 5~6개 · 챕터당 씬 6~12개(90~130초) · 총 30~70씬 · 540~660초

## 컷 리듬 — "한 문장 = 한 화면"

화면이 오래 머무는 것과 화면이 대본과 어긋나는 것은 **같은 문제**다. millong_001에서 실사 세그먼트 평균 8.22초·최대 13.5초였고, 클립 하나가 2~3문장을 덮으면 앞문장에 맞춰 고른 화면이 뒷문장에서 반드시 어긋났다.

- **한 씬을 한 덩어리 그림으로 상상할 수 있어야 한다.** 씬 안에서 **주장이 뒤집히면**("한국은 라인이 돌아갔다. **반면** 유럽은 닫았다") **씬을 둘로 쪼개라.** 한 씬에 담긴 이상 어떤 화면을 골라도 절반은 틀린다.
- **씬 길이 7~15초**(47~100자). 15초 초과는 한 호흡에 너무 많이 담았다는 뜻.
- ⚠️ **씬 길이 ≠ 컷 길이.** 씬은 나레이션 단위, 세그먼트는 화면 단위다. 15초 씬이라도 클립 3개면 5초 컷이다. 씬을 억지로 5초로 자르지 마라.
- `footage.visual_must`는 씬의 **첫 문장이 아니라 씬 전체**를 만족해야 한다.

### STEP 2 — 풋티지 수집 [S] (★가로 소재만)
v1.7부터 세로(ar<1.0) 후보는 **아예 버린다**. 4:3·1:1 기록영상은 허용(블러 여백), 16:9는 화면을 꽉 채운다.

**AI 컷 반입 = 소재등록 동시** — `ai_intake`가 라이브러리 등록(index·md5 중복차단·비율)까지 한다. `/ai소재등록`을 따로 부르지 않는다. 대신 반입 인자를 등록 품질로 채운다:
