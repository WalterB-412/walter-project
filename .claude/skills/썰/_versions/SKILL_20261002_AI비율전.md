# 썰 숏폼 자동화

작업 폴더: `01_자동화/썰_숏폼/`
산출 폴더: `02_콘텐츠/썰/NNN_YYYYMMDD_키워드/`
run_id: `ssul_NNN` (3자리 0패딩) · 작업 경로는 항상 `_work/ssul_NNN`

## 시작 전 반드시 읽을 것

```bash
ls 설계도_v*.md | sort -V | tail -1          # 파이프라인·게이트·실측 근거 전체
ls 사연_수집_브리프_v*.md | sort -V | tail -1  # 사연 선별 기준
ls AI_프롬프트_가이드_썰_v*.md | sort -V | tail -1  # AI 컷 6축 템플릿·금지 토큰
```

## 절대 규칙

1. **파일 덮어쓰기 금지** — 새 버전 생성, 구버전은 `_versions/`로. 삭제 금지.
2. **좌표는 `layout_ssul.json`에서만** 읽는다.
3. **한국 사연에 외국 소재 금지.** `locale: "KR"` 국적 게이트가 통화·지명·국적형용사·서양 생활지표를 차단한다.
4. **인물이 30% 이상** — 사람 얘기가 사물 슬라이드쇼가 되면 안 된다. 얼굴은 **자동 블러**(YuNet 0.40), 크롭하지 않는다(표정이 사연의 정보다).
5. **`ko_queries`는 한국어 한 단어로.** (`포장마차`·`분식집`·`고시원` O / `고시원 복도`·`이사 트럭` X — Commons 실측)
6. **눈검수 증거 강제** — `footage_review.json`에 `eyes: true` + `note`(12자↑, 무엇을 왜 골랐고 왜 버렸는지)가 없으면 게이트가 빌드를 막는다.
7. **PII 제거** — 실명·지명·직장명 등 특정 가능한 정보는 STEP 0에서 전부 치환한다.
8. **TTS 무료 10콜/일** — 대본(preflight) 확정 전에 부르지 않는다.

## 세션 4분할 ★토큰 절감 핵심

비용은 세션 길이의 **제곱**에 비례한다(실측 4.2배 차이). 썰은 눈검수 시트 이미지가 최대 토큰 싱크(12~13씬이면 이미지만 30~40K)라 분할 효과가 가장 크다.

| 세션 | 담당 STEP | 완료 조건 | 모델 |
|---|---|---|---|
| **S1 기획** | 0 사연·PII·locale/mood · 1 대본 · 2 preflight | `scenes.json` + preflight 통과 | Opus 필수 |
| **S2 음성·수집** | 3 TTS · 4 정렬 · 5 수집(+AI·웹 반입) | `footage_manifest.json` | Opus/Sonnet |
| **S3 눈검수** | 6 시트 열람·채택 · 6.5 소재 게이트 | `footage_review.json` + 게이트 통과 | **Opus 필수** (비전 판단) |
| **S4 출고** | 7 빌드 · 출고검수 · 캡션 | mp4 + caption.txt | Opus |

- 씬 10개 초과면 `review_sheet --only`로 S3a/S3b로 더 쪼갠다.
- `footage_review.json`은 씬 단위 배열이라 이어 써도 앞 세션 결과가 안 지워진다.
- **세션 인계는 handoff로** (상태파일 전량 19,568토큰 → handoff.md 1,165토큰 = 6%):
  ```bash
  python3 "$(ls handoff_ssul_v*.py|sort -V|tail -1)" --run ssul_NNN
  ```
  진행 단계를 파일 존재로 판정하고 stdout으로도 출력한다(Read 턴 절약).

## 파이프라인 STEP 0~7

### STEP 0 — 사연 반입·PII·locale/mood [C]
사연 원문 → `_work/ssul_NNN/source_text.md`
- `사연_수집_브리프` 기준으로 선별
- **PII 전면 치환**
- `locale`(KR 등) · `mood`(hard / neutral / warm) 확정 — 톤 게이트의 기준값이 된다

| mood | 밝기 상한 | 채도 상한 | 하한(뭉갬) |
|---|---|---|---|
| `hard` | 185 | 175 | 25 |
| `neutral` | 200 | 190 | 20 |
| `warm` | 225 | 215 | 20 |

### STEP 1 — 대본 [C]
→ `_work/ssul_NNN/scenes.json`
씬마다 필수 필드: `people: "yes"/"no"`, `visual_must`, `ko_queries`(한국어 한 단어), `locale`, `mood`

### STEP 2 — 프리플라이트 [S] ★게이트
```bash
python3 "$(ls preflight_ssul_v*.py|sort -V|tail -1)" _work/ssul_NNN
```
게이트: `[LOCALE]` `[PEOPLE]` `[AIP]` 등. **통과 전 TTS 금지.**

### STEP 3 — TTS [S]
```bash
python3 "$(ls tts_ssul_v*.py|sort -V|tail -1)" _work/ssul_NNN [--pitch 1.10] [--from-existing]
```
음성 후보 확인: `python3 "$(ls voice_sampler_ssul_v*.py|sort -V|tail -1)" all|f|m|stat`

### STEP 4 — 정렬 [S]
```bash
python3 "$(ls align_ssul_v*.py|sort -V|tail -1)" _work/ssul_NNN [--model small]
```

### STEP 5 — 소재 수집 [S]
```bash
python3 "$(ls footage_ssul_v*.py|sort -V|tail -1)" _work/ssul_NNN [--limit 3] [--only 6,9]
```
→ `footage_manifest.json`. 버린 이유까지 집계해 출력한다(`버림: 외국(dollar)×4 무관×7 저해상×3`).

보조 반입:
```bash
# AI 생성 컷 (AI_프롬프트_가이드 6축 준수)
python3 "$(ls ai_intake_ssul_v*.py|sort -V|tail -1)" --run ssul_NNN --scene N --file <경로> --desc "설명" --keywords "..."
# 웹 이미지 변형 반입 (출처·크레딧 필수)
python3 "$(ls web_intake_ssul_v*.py|sort -V|tail -1)" --run ssul_NNN --scene N --url <URL> --desc "설명" --credit "출처" [--crop-band] [--blur-box x,y,w,h]
```

### STEP 6 — 눈검수 [C+S] ★Opus 필수
```bash
python3 "$(ls review_sheet_ssul_v*.py|sort -V|tail -1)" _work/ssul_NNN [--only 5,8] [--cols 3]   # 후보 시트
python3 "$(ls review_sheet_ssul_v*.py|sort -V|tail -1)" _work/ssul_NNN --picked                  # 채택 전체 톤 확인
```
시트는 **미디어 밴드(1080×960) 크롭 상태 그대로** 타일링된다 — 세로 사진이 밴드에서 어떻게 잘리는지 원본 썸네일로는 안 보이기 때문.

**자동으로 못 막으니 눈으로 봐야 하는 것** (OCR·인종판정은 실패해서 채택 안 함):
- 사진 속 **영문 텍스트** (영문 계약서·간판)
- **서양식 공간·소품** (파인트 잔, 러버스탬프, 서양식 복도)
- 오탐/미탐 **블러**
- 광고컷 느낌 (언박싱·스튜디오 플랫레이)

채택 후 `footage_review.json`에 `eyes: true` + `note` 기록.

### STEP 6.5 — 소재 게이트 [S] ★차단
```bash
python3 "$(ls footage_gate_ssul_v*.py|sort -V|tail -1)" _work/ssul_NNN [--people-min 0.30] [--strict]
```
게이트: `[EYES]` `[PEOPLE]` `[TONE]` `[FOREIGN]` `[DUP]` `[RHYTHM]` `[WEB]`

### STEP 7 — 빌드·출고 [S+C]
```bash
python3 "$(ls video_build_ssul_v*.py|sort -V|tail -1)" _work/ssul_NNN --out "../../02_콘텐츠/썰/NNN_YYYYMMDD_키워드"
python3 "$(ls youtube_ts_ssul_v*.py|sort -V|tail -1)" --run ssul_NNN --video <mp4경로>
```
출고 검수 후 `caption.txt` 작성. **폴더명에 `(완료)`를 붙이지 않는다** — Walter가 최종 검수·수기 수정 후 직접 붙인다.
