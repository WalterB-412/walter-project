Walter 위키를 영역별로 순서대로 점검하며, 질문 하나씩 받아 변경사항을 반영한다.

# 위키 루트
/Users/kakao/Documents/2. 개인/Walter Project/03_위키/Walter_위키/Walter의 상상은 현실이 된다/

# 입력
$ARGUMENTS  (생략 가능 — 특정 영역만 업데이트하려면 영역명 입력. 예: "재무" "프로젝트" "일일")

# 시작 전 준비
1. 위키 루트/log.md 마지막 update 엔트리 확인 (마지막 업데이트 날짜 파악)
2. 위키 루트/index.md 읽기 (현재 노트 목록 파악)
3. 오늘 날짜 기준으로 인터뷰 시작

# 인터뷰 순서 (영역별, 하나씩)

다음 순서로 진행. $ARGUMENTS로 영역 지정 시 해당 영역만.

---

**영역 1 — 재무·투자** (`03_재무/`)

질문 1-A (수입현황.md 업데이트):
> "이번 달 수입 알려줘요. 본업 + 부업 항목별로요.
> 예: 본업 350만, 블로그 2만, 유튜브 0, AI음원 0"
- 답변 받으면 `수입현황.md` 월별 수입 테이블 해당 월 행에 입력
- "패스" → 다음 질문으로

질문 1-B (ETF현황.md 업데이트):
> "이번 달 ETF 배당 받은 거 있어요? (종목별 수령액)"
- 답변 받으면 `ETF현황.md` 월별 배당금 테이블 해당 월 행에 입력
- ETF 수량·평가금액 변동이 있으면 포트폴리오 테이블도 업데이트
- "패스" → 다음 영역으로

---

**영역 2 — 프로젝트·부업** (`01_프로젝트/`, `06_콘텐츠_파이프라인/`)

질문 2-A (콘텐츠 발행 기록):
> "지난번 업데이트 이후 발행한 콘텐츠 있어요?
> 예: 블로그 3편(제목), 클립 1편, 인스타 카드뉴스 2장"
- 발행 완료 항목 → `블로그_아이템.md` / `유튜브_아이템.md` / `인스타_아이템.md` / `쓰레드_아이템.md` 발행 완료 테이블에 append
- 해당 성장 노트(`블로그 성장.md` 등) 월별 성과 추적 테이블 업데이트

질문 2-B (프로젝트 진척):
> "진행 중인 자동화·프로젝트 중 새 진척이나 막힌 것 있어요?"
- 해당 프로젝트 노트 진행 기록 테이블에 append

---

**영역 3 — 가족** (`02_가족/`)

질문 3-A:
> "가족 관련 기록할 일 있어요? (기념일, 건강, 일정, 관계 변화 등)"
- 해당 인물 노트에 append
- 일정은 `기념일.md` 또는 해당 인물 노트의 🗓️ 일정·여행 섹션에 기록

---

**영역 4 — 지식** (`04_지식/`)

질문 4-A:
> "저장해둘 인사이트·노하우·배운 것 있어요? (있으면 raw/notes에 ingest 권장)"
- 짧은 메모 수준이면 해당 지식 노트에 직접 append
- 분량이 있으면 `/ingest` 권장 안내

---

**영역 5 — 일일기록** (`05_일일기록/`)

질문 5-A:
> "오늘 하루 한 줄 회고 남길 거 있어요?"
- 답변 있으면 `05_일일기록/YYYY-MM-DD.md` 생성 (없으면 신규 생성)
- 파일 구조: 99_템플릿/일일노트_템플릿.md 기반
- "패스" → 완료 처리

# 진행 규칙

- **질문은 반드시 하나씩** — 답 받으면 처리 후 다음 질문
- 답이 "없음" / "패스" / "ㄴㄴ" → 해당 질문·영역 건너뜀
- 답이 있으면 즉시 해당 노트에 반영 후 "✓ 반영했어요" 한 줄 출력, 다음 질문으로
- 기존 노트가 있으면 업데이트, 없으면 새 노트 생성 (frontmatter 포함)
- 질문 맥락: 마지막 update 로그 날짜 기준으로 "그 이후" 변동사항 물어볼 것
- 수치는 추측하지 않음 — 반드시 사용자 입력값만 기록

# 노트 업데이트 규칙

- frontmatter: `area`, `created`, `sources`, `tags` 유지 (created는 최초 생성일 고정)
- 수치·날짜 업데이트 시 기존 값 위에 덮지 말고 해당 월 행에 입력 또는 날짜 prefix로 append
- 파일 덮어쓰기 금지 → 기존 파일 내용 유지하며 해당 섹션만 수정
- cross-link 3개 유지 원칙

# 완료 처리

모든 영역 인터뷰 종료 후:
1. log.md append: `## [YYYY-MM-DD] update | 반영 영역: {목록}`
2. 요약 출력:
   - 업데이트된 노트 목록
   - 건너뛴 영역
   - 다음 /update-wiki 권장 시점 (재무는 월 1회, 프로젝트는 주 1회)

# 제약
- raw/ 절대 수정 X
- 사용자 답변 없는 내용 임의 추가·추측 금지
- log.md 엔트리는 update 완료 후 1회만 append
