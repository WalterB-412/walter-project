# 롱폼 정보 그래픽 스펙 v1.0 (2026-10-12)

> 렌더러: `docu_graphic_v1.0.mjs` · 합성: `military_build_v1.5.py` · 게이트: `preflight_mil_v2.0.py`
> 목적: **실사 영상으로는 보여줄 수 없는 정보**(위치·거리·숫자 비교·시간 순서)만 HTML로 그려 영상 소재로 쓴다.

## 1. 언제 그래픽을 쓰나 — 선정 기준

대본을 다 쓴 뒤 씬마다 "이 문장을 **실사 화면으로** 보여줄 수 있나?"를 먼저 묻는다.
아래 표의 '그래픽' 칸에 해당하고 실사로는 대체가 안 될 때만 `footage.type: "graphic"`으로 바꾼다.

| 문장 유형 | 그래픽 | kind | 실사가 더 나은 경우(그래픽 금지) |
|---|---|---|---|
| "A에서 B까지", 위치·지명·작전 구역 | ✅ | `map` (points·routes·lines) | 그 장소의 실제 영상이 있으면 실사 + `location` 슈퍼 |
| 사거리·작전반경·위협 범위 | ✅ | `map` (rings) | — |
| 수출국·배치국 나열(3개국 이상) | ✅ | `map` (highlight) | 1~2개국이면 국기·현지 영상 |
| 핵심 숫자 하나가 이야기의 전환점 | ✅ | `big_number` | 숫자가 장면의 부속이면 자막으로 충분 |
| 2~4개 대상의 수치 비교 | ✅ | `stat_compare` | — |
| 개발·배치·실전·수출 연대기 | ✅ | `timeline` | 사건 하나를 다루면 실사 + `location` |
| 제원 3개 이상 나란히 비교 | ✅ | `spec_table` | 제원 1개는 문장으로 |
| 무기가 움직이는 모습, 사람, 현장 | ❌ | — | **항상 실사**(그래픽 금지) |

**비중 규칙** (layout.json `graphics`, preflight가 검사)
- 전체 길이의 **20% 이하**(초과 시 빌드 차단), 목표 **10~15%** (10분 기준 60~90초, 카드 10~15장)
- 그래픽만 있는 씬은 **2개까지만 연속**, 한 챕터 안 비중 **35% 이하**
- **콜드오픈(인사 전)에는 그래픽 금지** — 첫 화면은 실사로 사건 한복판을 보여준다
- 그래픽 1장 = 메시지 1개. 화면에서 읽을 시간은 5~8초

**사실 규칙** (preflight `[GFX-SOURCE]`)
- 그래픽 씬에는 `fact_ids`를 반드시 단다 — 그래픽 속 숫자·연도·지명은 전부 facts.json 근거가 있어야 한다
- `graphic.source`를 반드시 채운다 — 화면 하단에 그대로 찍힌다(예: `"출처: SIPRI Arms Transfers Database (2026)"`)
- 지도 데이터는 Natural Earth(퍼블릭 도메인). 구글 지도 캡처·언론사 그래픽 캡처는 금지

## 2. 화면 규칙 (렌더러가 자동 적용)

- 1920×1080, 어두운 배경, 강조색 앰버(#e8b04b), 보조색 블루(#5aa9e6). 글꼴은 layout.json `fonts.main`(GoshinGothic)
- **y 800 아래는 비워 둔다** — 나레이션 자막 띠가 그래픽 위에도 올라오기 때문이다
- 애니메이션 3.2초 → 이후 완성 화면 유지. 씬이 4초보다 길면 빌드가 마지막 프레임을 멈춰서 늘린다
- 산출물: `_work/<run>/graphics/scene_<id>.mp4`(애니메이션) · `@2x.png`(정지화면) · `.html`(브라우저로 열어 디버그)

## 3. JSON 스펙

> 아래 예시의 수치·좌표는 **형식 설명용**이다(팩트 미검증). 실제 편에서는 facts.json 근거 값으로 채운다.

공통 필드: `kind`(필수), `title`(필수), `subtitle`(선택, 이탤릭 한 줄), `source`(필수)

### big_number — 핵심 숫자 1개
```json
{"kind": "big_number", "title": "제1연평해전 교전 시간",
 "value": "14", "unit": "분", "label": "교전 개시부터 북한 경비정 퇴각까지",
 "sub": "1999년 6월 15일 09:28 ~ 09:42", "source": "출처: 국방부 『국방백서』"}
```
`value`가 숫자면 0부터 올라가는 카운트업, 문자면 그대로 표시.

### stat_compare — 2~4개 막대 비교
```json
{"kind": "stat_compare", "title": "자주포 최대 사거리 비교", "subtitle": "표준탄 기준 · 제조사 공개 수치",
 "unit": "km",
 "items": [{"label": "K9 썬더", "value": 40, "highlight": true},
           {"label": "M109A6 팔라딘", "value": 30},
           {"label": "PzH 2000", "value": 40, "value_label": "40+"}],
 "source": "출처: 각 제조사 제품 자료"}
```
**조건이 다른 수치는 한 막대에 놓지 않는다**(예: 사거리연장탄 vs 표준탄). 조건은 subtitle에 적는다.

### timeline — 3~6개 지점
```json
{"kind": "timeline", "title": "K9 자주포 연대기",
 "points": [{"year": "1989", "label": "개발 착수"},
            {"year": "1999", "label": "국군 배치"},
            {"year": "2022", "label": "폴란드 계약", "highlight": true}],
 "source": "출처: 방위사업청"}
```

### spec_table — 최대 5행 × 3열
```json
{"kind": "spec_table", "title": "제원 비교",
 "columns": ["", "K9A1", "M109A7"],
 "rows": [["최대 사거리", "40 km", "30 km"], ["전투중량", "47 t", "35 t"]],
 "source": "출처: 각 제조사 공개 자료"}
```

### map — 지도 (국가 강조 · 지점 · 경로 · 경계선 · 원)
```json
{"kind": "map", "title": "연평도와 북방한계선", "subtitle": "서해 5도 일대",
 "bbox": [124.2, 37.3, 126.9, 38.4],
 "highlight": [{"country": "북한", "label": "북한"}],
 "points": [{"lon": 125.7, "lat": 37.66, "label": "연평도"}],
 "lines": [{"coords": [[124.1, 37.62], [125.4, 37.55], [126.1, 37.67]], "label": "북방한계선", "label_at": 0}],
 "routes": [{"from": "대한민국", "to": "폴란드"}],
 "rings": [{"center": [126.6, 38.1], "radius_km": 60, "label": "사거리 60km"}],
 "source": "지도: Natural Earth · 경계선: 국방부 발표 좌표"}
```
- 국가는 한국어 이름으로 쓸 수 있다(렌더러 내장 사전 약 50개국 — 대한민국·북한·미국·폴란드·노르웨이·튀르키예·인도·호주 등). 사전에 없으면 Natural Earth 영문명(`"Czechia"`)을 쓴다.
- `bbox`[서경, 남위, 동경, 북위]를 주면 그 범위로 확대한다. 없으면 표시 요소 전체가 들어가게 자동으로 맞춘다.
- 해상도는 범위에 따라 자동 선택(좁으면 10m, 대륙 단위 50m, 세계 110m). 대륙 간 범위는 왜곡이 적은 투영으로 바뀐다.
- **경계선·좌표는 반드시 출처가 있는 값**을 쓴다(NLL·군사분계선 등은 공식 발표 좌표). 임의로 그은 선은 사실 왜곡이다.
- 라벨이 겹치면 렌더러가 아래로 밀어낸다. 그래도 겹치면 `label_dx`·`label_dy`로 조정.

### route — (v1.3 스타일가이드 호환)
`{"kind":"route","from":"대한민국","to":"폴란드","note":"…"}` → 자동으로 map(두 나라 강조 + 경로)으로 바뀐다.

## 4. 실행

```bash
npm i                                                         # 최초 1회 (package.json)
node docu_graphic_v1.0.mjs --run-id millong_NNN               # 전체 graphic 씬
node docu_graphic_v1.0.mjs --run-id millong_NNN --scene 12    # 한 씬만 다시
node docu_graphic_v1.0.mjs --run-id millong_NNN --html-only   # 캡처 없이 HTML만(빠른 확인)
```
실행 시점: **STEP 1.5**(대본 확정 후, STEP 2 수집 전). footage_collect v1.7이 `graphics/index.json`을 읽어 mp4를 우선 등재한다.
