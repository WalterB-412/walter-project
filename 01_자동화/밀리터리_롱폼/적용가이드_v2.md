## 2. 로컬 적용 순서 (Mac, `01_자동화/밀리터리_롱폼/`)

1. 이 폴더의 새 파일을 로컬 롱폼 폴더에 복사한다(기존 버전 파일은 그대로 둬도 된다 — 스크립트는 `ls *_v*|sort -V|tail -1`로 최신만 쓴다):
   `footage_collect_v1.7.py` · `preflight_mil_v2.0.py` · `military_build_v1.5.py` · `docu_graphic_v1.0.mjs` ·
   `layout.json`(덮어쓰기) · `package.json` · `대본_스타일가이드_v1.4.md` · `그래픽_스펙_v1.0.md`
2. 폰트: 롱폼 `assets/fonts/`에 GoshinGothic-SemiBold.ttf 심링크를 만든다.
   ```bash
   ln -s "../../../밀리터리_숏폼/assets/fonts/GoshinGothic-SemiBold.ttf" assets/fonts/GoshinGothic-SemiBold.ttf
   ```
   (안 해도 `layout.json` fonts.fallbacks가 `../밀리터리_숏폼/assets/fonts/`를 찾는다. 빌드 로그 `폰트:` 줄로 확인)
3. 그래픽 렌더러 의존성: 롱폼 폴더에서 `npm i` 1회.
4. 스모크 테스트: 기존 런 하나를 복사해 `chapter_title`·`quote`·`location`·graphic 씬 1개씩 넣고 STEP 1.5 → 5 → 6.

## 3. ⚠️ 진행 중인 런(구 방식)이 있다면

- `layout.json`은 공용이라 바꾸는 순간 **구 빌드(v1.4)에도 새 폰트·고지 위치가 적용**된다(나머지는 그대로).
- 구 방식 그대로 끝내려면: `layout.json`의 `"chapter_mode": "card"`, `"fit": {"fullbleed_landscape": false}`로 바꿔 빌드하고,
  preflight는 `python3 preflight_mil_v1.9.py --run-id …`로 직접 지정한다(v2.0은 세로 0건·[HYPE]로 막힐 수 있다).
