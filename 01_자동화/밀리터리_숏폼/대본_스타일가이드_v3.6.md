## 1. 타깃과 톤

주 시청층은 **40~60대 남성**. 개발도상국 시절을 살아본 세대의 인정 욕구가 기저라, 초라한 과거 → 현재 위상의 역전 서사에 가장 강하게 반응한다.

## 2. 심리 엔진 6종

**영상 1편 = 주 엔진 1개 + 보조 엔진 1개.** scenes.json 최상위에 기록한다: `"engine": {"primary":"F","secondary":"A"}`. 주 엔진 F를 고르면 `frame:"contest"`와 `conflict_axis`가 따라오고 preflight `[CONTEST]`가 켜진다(§12).

| 엔진 | 공식 | 예 | 주의 |
|---|---|---|---|
| **A 인정** | 외국의 실제 발언·계약·평가 인용 | "폴란드 국방장관이 직접 말했습니다. '한국만큼 빨리 주는 나라가 없다'고요." | 주어 없는 인정("전 세계가 경악") 금지. 원문+매체를 facts에 |
| **B 역전** | [과거의 구체적 초라함] → 그런데 지금은 → [현재 수치] | "소총 한 자루 못 만들어 미국에 빌려 쓰던 나라가, 지금은 그 미국이 K9을 테스트합니다." | 과거 팩트도 연도·사건 검증 |
| **C 비교** | [경쟁국 수치] vs [한국 수치] → 체감 단위 | "독일 레오파르트 납기는 7년입니다. K2는 계약하고 첫 전차까지 1년이 안 걸렸습니다." | 비하 없이 숫자로만. 양쪽 출처 필수 |
| **D 위협→해소** | [실재 위협] → 불안 → 그런데 → [한국의 대응] → 안도 | "북한 방사포는 수도권까지 4분입니다. 그런데 이 4분을 노리고 만든 무기가 있습니다." | 위협도 팩트만 |
| **E 소속** | 시청자를 지분 보유자로 | "이 미사일, 당신이 낸 세금으로 만들어진 겁니다." | CTA 직전 배치 최적 |
| **F 전략 대결** | [상대의 수(관측된 행동)] → [압박·빈틈] → [우리의 수] → [판의 변화] | mil_129: 중국이 암초에 활주로를 판다 → 필리핀 하늘이 사정권 → 필리핀이 FA-50을 12대 더 산다 | 상세 §12. 상대의 수도 팩트, 상대를 악당으로 만들지 않는다 |

**C와 F 구분:** 비교표로 끝나면 C, "왜 그걸 골랐나"(판)를 캐면 F.

## 3. 비트 구조와 길이

### 3-1. 비트 (scenes.json `beat`)

| 비트 | 씬 수 | 역할 |
|---|---|---|
| HOOK | 1 | 사건 한복판 또는 결론부터. 정체·핵심 수치는 감춘다. **≤30자** |
| TENSION | 1~3 | 떡밥(오픈 루프)·위기. 엔진 B면 초라한 과거 |
| VALUE | 2~4 | 핵심 팩트. 씬당 팩트 1 + 체감 환산 1. **첫 VALUE = 정체공개 씬(`reveal:true`)** |
| PROOF | 1~2 | 결정타 — 인용·계약·시험 결과. 아껴둔 숫자를 여기서 터뜨린다 |
| CTA | 1~2 | 오프닝 콜백 + 애국 마무리. **≤80자(문장 상한도 80)** |

- 시간 감각: HOOK 0~4초(현재형 중계, 결론 없음) → 떡밥 ~8초 → 위기 ~15초 → 정체공개 ~22초 → 숫자 정산 ~32초 → CTA. 뉴스 요약이 아니라 **하나의 사건을 시간순으로 재구성**하고, 핵심 수치는 PROOF까지 아낀다.
- 마지막 3씬은 **급하지 않은 착지**: [-2] 위력·파장의 정점 → [-1] 소속·의미로 감속 → [CTA] 오프닝 콜백 + 마무리.
- CTA 마무리 계열: "대한민국을 응원합니다." / "이게 대한민국입니다." / "우리는 계속 갑니다." 놓침 압박형·프로필 안내형 금지. 다음 편 예고는 caption.txt에서.
- 상단 제목 밴드는 핵심 수치를 스포일러하지 않는 궁금형. **훅 나레이션과 제목 밴드 문구는 다르게.**

### 3-2. 길이 — 길이는 상한이 아니라 결과다

**글자수에 대본을 맞추지 말고, 이야기가 완결되는 길이를 대본이 정하게 한다.** 압축하면 제일 먼저 씬 사이 인과의 다리가 잘린다. 유튜브 쇼츠 기준은 절대 길이가 아니라 완주율이다.

| 항목 | 값 | 비고 |
|---|---|---|
| 총 길이 | 목표 **55~75초** / 허용 최대 90초(preflight 95초) / **50초 미만 차단** | |
| 씬 수 | **7~18** | |
| 총 나레이션 | 450~620자 | 낭독 8.3자/초 · rate 1.1. 하한이 더 중요 |
| 문장 | **≤40자** | HOOK ≤30 · CTA ≤80 |
| 씬 | **≤70자**(문장 1~3개) | 씬당 클립 2개 × 4.5초 ≈ 75자가 물리 제약 |

- **길면 문장을 깎지 말고 나눠서 같은 씬에 이어 쓴다.** 씬 분할은 화면을 바꿔야 할 이유가 있을 때만(씬 1개 = footage·why·beat·소재·눈검수 추가 비용).
- 길이 확인은 산문을 다 쓰고 **소리 내어 읽은 뒤**에만. 90초를 넘으면 **가장 약한 정보 씬을 통째로 덜어낸다**(문장 압축 금지).
- 초안에 "N자"·"N초" 같은 길이 표기를 남기지 않는다 — 세는 순간 설명 절부터 잘린다(`[COUNTED]` 경고).

## 4. 쉬운 언어

### 4-1. 군사용어 3초 번역
용어는 써도 된다. **등장 즉시 한 줄 풀이.** 공식: `[용어], 쉽게 말해 [일상 비유]입니다.`
- "CIWS, 쉽게 말해 군함의 최후의 방패입니다."

### 4-2. 체감 환산 (규칙 E와 한 세트)
원수치를 먼저 말하고 **그다음** 환산을 붙인다. 환산값도 계산식을 facts.json에 기록한다.

| 원 수치 | 체감 환산 |
|---|---|
| 사거리 400km | 서울에서 부산까지 닿는 거리 |
| 3조 원 | 국민 1인당 6만 원씩 걷은 돈 |
| 분당 6발 | 10초에 한 발 |

- ✅ "탄두 무게만 8톤입니다. 아파트 한 층 무게죠."

### 4-3. 구어체
- 문어체 초안을 말하듯 다듬는다: "K2 전차의 납기 준수는 계약 경쟁력의 핵심이다" ❌ → "K2가 왜 팔리느냐. 약속한 날짜에 진짜로 줍니다." ✅
- 짧은 문장이 기본(15자 안팎). 긴 문장은 쉼표로 끊지 말고 **두 문장으로 나눈다.**

## 5. ★문장 규칙 (v3.6 정비 — 시청자가 읽는 자막과 듣는 낭독 모두에 적용)

**자막은 대본 문장을 그대로 보여준다.** 낭독용 쉼표가 자막에서는 맞춤법 오류로 보인다는 점을 늘 기억한다.

### 5-1. 문장은 서술어로 끝낸다 (명사 종결 조각 제한)
- **명사로 끝나는 조각 문장은 편당 1회까지**, 숫자 강타 용도로만 쓴다. 바로 다음 문장은 **주어가 있는 완결 문장**이어야 한다.
  - ✅ "17조. 폴란드 계약 하나가 이 크기입니다."
  - ❌ "이름은 현무-5." / "탄두만 8톤." / "우리 손으로 만든 울산급." → "이름은 현무-5입니다." / "탄두 무게만 8톤입니다." / "우리 손으로 만든 울산급이었습니다."
- 동사가 있는 짧은 문장의 연타는 허용한다: "1년. 끝났습니다. 폴란드가 사인했죠." (조각은 "1년." 하나)
- 명사구를 쉼표로 이어 붙여 성분 호응이 깨지는 문장 금지:
  - ❌ "로켓으로 하늘을 뒤덮는다는 뜻의 이름, 별명이 강철비죠"
  - ✅ "별명은 강철비입니다. 로켓으로 하늘을 뒤덮는다는 뜻이죠."

### 5-2. 쉼표는 최소로
- **한 문장에 쉼표 1개까지.** 주어(이/가/은/는) 바로 뒤와 문장 첫 접속사 뒤에는 쉼표를 찍지 않는다.
  - ❌ "북한이, 핵보다 이걸 더 무서워합니다." / "그런데, 미국이 움직였습니다."
  - ✅ "북한이 핵보다 이걸 더 무서워합니다." / "그런데 미국이 움직였습니다."
- 예외 하나 — **숫자 강타 직전의 쉼**: "요격률이, 96%." 같은 형태는 편당 1회까지.
- 나열 쉼표("폴란드, 루마니아, 노르웨이")는 정상 문장부호라 허용한다.
- 쉼이 더 필요하면 쉼표를 늘리지 말고 **마침표로 문장을 나눈다.** (자막·TTS 텍스트 분리는 코드 작업으로 별도 진행 예정 — 그 전까지 이 규칙으로 버틴다)

### 5-3. 어미
- 니다체+요체+질문을 섞되, **같은 어미 4연속 금지**("~입니다"가 이어지는 것 자체는 괜찮다. 억지로 바꾸지 않는다).
- 리듬은 어미를 바꿔서가 아니라 **문장 길이**로 만든다.
- **"~거든요"는 앞 문장에 그 이유를 받을 내용이 있을 때만.** ❌ 이유 없이 붙인 "이제 못 숨거든요" → ✅ "지하 100미터 벙커도 이제는 숨을 곳이 못 됩니다."
- 의문문 1회 이상, 1인 2역 반문+답 영상당 1회: "비싸다고요? 독일제 절반 값입니다."
- 현재형 중계 허용("점이 뜹니다"). 구어 완충어("근데", "사실") 허용.

### 5-4. 번역투 금지
- "~를 통해", "~에 의해", "~되어지다", "이례적으로(인용 아닌데)", "~에 있어서" 를 쓰지 않는다.
- 영어 출처를 직역하지 말고 facts.json의 **`claim_ko`**(§7)에서 문장을 가져온다.

### 5-5. 단어 선택
- **탈것은 "짓다"로 만들지 않는다.** 배·함정·잠수함·항공기·전차·미사일은 "만들다"(1순위)·"건조하다". 짓는 것은 건물(집·공장·발전소·다리)뿐. 관용구("미소를 짓다·이름을 짓다·결론을 짓다·농사를 짓다")는 예외. `[VERB]` 차단.
- 금액은 숫자를 살려 쓴다("척당 7천억 원"). 낭독 변환은 코드 책임 — 새 단위(경·유로·위안)에서 `[MONEY]` 경고가 뜨면 대본이 아니라 `tts_run_mil`의 `_UNITS_RE`를 고친다.
- 신규 제식명은 tts `WEAPON_SPEAK` 사전에 1줄 추가.
- 물결(~)은 되도록 "에서"로. 영문 약어 남발·괄호 지문 금지.
- **`[pause]`·`[pause long]` 태그 금지.** 쉼은 마침표로 만든다(Chirp3-HD에서 태그가 버벅임의 원인이었다. 잔존 태그는 tts가 정화하지만 신규 작성 시 0개).

## 6. 자극·재미·훅

### 6-1. 자극은 사실에 앵커
- "초토화·인공지진·괴물·박살·경악" 같은 표현은 **facts.json에 근거(또는 실제 언론 표현)가 있을 때만.**
- 적(북한·중국)의 공포·견제는 **보도된 반응이 팩트로 있을 때만** 쓴다(§12-3).

### 6-2. 재미 3종 (편당 2개 이상)
- **아이러니**: "핵도 없는데 핵보다 무섭다"
- **체감 비유**: "10톤 쇳덩이가 마하 10으로 떨어지는 겁니다"
- **적 리액션**: 북한·중국을 조연으로(보도 근거 내)

### 6-3. 자극 장치
1. **결정타 단문 연타** — 동사가 있는 짧은 문장으로(§5-1).
2. **침묵 직전 훅** — 문장 절반쯤은 다음이 궁금하게 끝낸다. 씬 마지막 문장이 다음 씬을 예고: "근데 미국이 이걸 보고 이상한 요청을 합니다."
3. **숫자 먼저** — 씬 첫머리에 수치: "17조. 폴란드 계약 하나가 이 크기입니다."
4. **루프 엔딩** — 마지막 문장이 첫 훅과 이어지게(재시청 유도). **단, 회수는 정서로 하고 없는 인과를 만들지 않는다**(mil_114):
   - ✗ "이제 그 하늘을 103발이 채웁니다" (103발이 드론을 잡는다는 근거 없음)
   - ✅ "이제 그 하늘을 지킬 손이 하나 더 늘어납니다"

### 6-4. 훅 공식 13종 (첫 2초, 관찰형 서술 금지)

| # | 유형 | 예 |
|---|---|---|
| 1 | 수치 강타 | "17조. 계약서 한 장 값입니다." |
| 2 | 가짜 상식 파괴 | "한국은 무기 수입국이라고요? 작년에 세계 8위 수출국이었습니다." |
| 3 | 인정 인용 | "미군 장성이 K9을 보고 한 말, '우리도 이건 못 만든다.'" |
| 4 | 역전 낙차 | "소총도 못 만들던 나라의 전차를, 유럽이 줄 서서 삽니다." |
| 5 | 금지된 질문 | "왜 미국은 한국에만 이 기술을 줬을까요?" |

## 7. 팩트 연동 (facts.json 강제)

**facts.json에 없는 문장은 대본에 못 들어간다.**

| 문장 유형 | facts.json 필수 |
|---|---|
| 수치 | 값 + 출처 URL + 조회일 |
| 인용 (엔진 A) | 원문 + 발화자 + 매체 + 날짜. 번역 시 원문 병기 |
| 과거 사실 (엔진 B) | 연도 + 출처 |
| 체감 환산 | 계산식 (예: 3조÷5,100만 명=5.9만 원) |
| 비교 수치 (엔진 C) | 양쪽 모두 출처 |

**필드:**

| 필드 | 언제 | 왜 |
|---|---|---|
| `scope` | 용도·범위 한계가 있을 때 | 대본이 용도를 마음대로 정하지 못하게 |
| `caveat` | 잠정·미확정 등 단서가 있을 때 | 완료형 주장 방지 |
| `source_thesis` | 출처가 있는 모든 팩트 | 기사 전체 논지 한 줄 — 논지와 반대로 한 조각만 뽑는 인용 왜곡 방지 |
| **`claim_ko`** ★v3.6 | 출처가 외국어일 때 | 직역 아닌 **우리말 풀이 한 문장**. 원문 `claim`은 그대로 둔다(뜻 변형 방지용 대조) |

```json
{"id":"f06", "claim":"F-15K·KF-16·F-35A가 운용하는 단거리 공대공 미사일 재고 보충분이다",
 "scope":"공대공 재고 보충·유지용 물량이다. 소형 무인기 요격 전용 도입이 아니다.",
 "source_thesis":"북한 위협 증가에 대응해 공대공 미사일 비축량을 늘리는 흐름을 다룬 기사."}
```

`scope`·`caveat`가 붙은 팩트를 인용한 씬은 **`scope_ok`**에 "이 문장이 왜 그 제한을 넘지 않는가"를 적는다(`[SCOPE]` 차단). 적을 말이 없으면 그 문장이 과장이다.

## 9. 작성 절차 — 산문이 정본이다

씬 단위(JSON)로 처음부터 쓰면 각 씬은 그럴듯해도 이음매가 끊긴다. 접속사는 논리를 표시할 뿐 생성하지 못한다.

**1a. 산문 먼저** — 씬 번호·JSON 없이 한 문단 통짜로 쓴다. 글자수를 세지 않는다. 소리 내어 이어 읽어 걸리는 데가 없을 때까지 고친 뒤 길이를 확인한다(§3-2). `_work/<run>/script_draft.md`의 **`## 산문 (정본)`** 헤딩 아래에 산문만 둔다(검수 메모·엔진 결정·인계 메모는 다른 헤딩).

**1b. 문장 경계에서 7~18조각으로 나눈다** — beat·footage·why를 붙인다. **나누면서 문장을 새로 쓰지 않는다.** 길이가 안 맞으면 분할 지점을 옮긴다. 한 씬에 문장 1~3개(70자)를 넣을 수 있고, "A. 그래서 B." 인과 쌍은 한 씬에 같이 넣는 것이 기본값이다.

**초안 대조 게이트 (preflight, 차단):**

| 게이트 | 걸리는 경우 |
|---|---|
| `[REWRITE]` | 초안 문장과 씬 문장의 유사도 0.85 미만(고쳐 씀) |
| `[REWRITE-NEW]` | 초안에 없는 문장을 1b에서 지어냄 |
| `[REWRITE-CUT]` | 유사도는 통과했지만 정규화 글자수가 4자 이상 줄어듦(절 삭제) |

- 한 문장을 두 씬으로 나눈 것은 통과. 초안에서 통째로 버린 문장은 보지 않는다. **쓰기로 한 문장은 그대로 쓴다.**
- 1c·1d 교정도 **초안에 반영하고 다시 나눈다.** 씬에서 바로 고친 문장은 검수를 건너뛴 문장이다.

| 초안 | 씬 | 잃은 것 |
|---|---|---|
| 그래서 오늘도 표적 드론을 띄워 놓고, 93년 된 총으로 그 작은 점을 겨눕니다 | …띄워 놓고 그 작은 점을 겨눕니다 | 그 편의 핵심 아이러니(mil_142) |
| 납기와 가격, 산업 협력 | 납기와 가격 | 구매 이유 하나(mil_145, 유사도 0.93) |

**1c. 초면 청자 검수** — §10-I.
**1d. 청자 도출 명제** — §11-1.

## 10. 흐름 규칙 9종 (A~I)

A~H는 씬과 씬 **사이**를, I는 문장 **내부**를 본다.

### A. ★관계 일치 (v3.6 개정 — 커넥터 의무 폐지)
정보 씬(TENSION/VALUE/PROOF)은 앞 씬과의 관계를 scenes.json **`rel`** 에 적는다: `인과 | 대조 | 심화 | 시간 | 없음`.
- 커넥터는 **선택**이다. 붙였다면 **`rel`과 뜻이 맞아야 한다.** 대조가 아닌데 "그런데", 인과가 아닌데 "그래서"는 금지 — 시청자에게는 "말이 안 되는 문장"으로 들린다.
  - 인과: 그래서·그 결과·덕분에 / 대조: 그런데·하지만·문제는·오히려 / 심화: 게다가·여기에·더 놀라운 건 / 시간: 그러자·그 순간·그렇게
- `rel:"없음"`(앞 씬과 관계없이 새 사실로 시작)은 **편당 2회까지.** 넘으면 리스트 읽는 느낌이 난다 — 순서를 바꾸거나 다리 절을 넣는다.
- 같은 커넥터 3연속 금지.
- 커넥터를 붙였다고 인과가 성립하지는 않는다 — 실제 성립은 G로 본다.

### B. 오픈루프 쌍
던진 떡밥은 **4씬 안에** 회수한다. HOOK의 큰 루프는 CTA에서 오프닝 콜백으로 닫는다. scenes.json `loop_open`/`loop_close`에 같은 라벨.

### C. 정체공개 씬
HOOK~TENSION에서 "이 무기"로 감췄다면 첫 VALUE 씬에서 고유명사를 처음 소리 낸다(`reveal:true`). "이 자주포의 이름은 K9입니다. 한국이 만들었습니다." 끝까지 안 밝히면 이탈한다(mil_004).

### D. 지시대명사 상한
"이 무기/부대/전차" 지시 표현 **연속 3씬 금지.** 정체공개 후 고유명사를 최소 2회 쓴다.

### E. 숫자 3연쇄
[원수치] → [체감 환산] → [그래서 뭐가 대단한지]. "개발까지 10년 6개월이 걸렸습니다. 초등학생이 대학생 되는 시간입니다. 그 안에 4.5세대 전투기를 해냈죠." 숫자 씬이 연속되면 뒤 씬은 비교·누적으로 잇는다.

### F. CTA 주어 정합
"대한민국을 응원합니다"의 주어는 화자(우리)다. 앞 문장 주어(전차·부대)가 이어져 읽히지 않게 마침표로 끊는다(mil_008).

### G. 인과 한 칸 (자동 검사 불가 — 작성자가 직접)
정보 씬마다 **"이 문장, 왜?"** 를 묻고, 답이 **바로 앞 씬 안에** 있어야 한다. 2단계 추론이나 대본 밖 배경지식이 필요하면 실패 → ①다리 절 추가 또는 ②중간 씬 추가. 수출 전략·계약·정치처럼 추상적인 주제에서 특히 잘 끊긴다.
- ✗ "그래서 한화는 발사대를 아예 분리했습니다." → "그러자 폴란드도 프랑스도 자기네 트럭에 천무를 얹기로 했습니다."
- ✅ 가운데에 "이제 어떤 트럭에도 얹을 수 있게 된 겁니다."를 넣는다(mil_015).

### H. why 필드
정보 씬마다 `"why"`: 이 문장이 왜 여기 나오는가(답은 바로 앞 씬 내용만으로). 빈 값·너무 짧음·text 복사는 preflight 차단. **why가 안 써지는 씬 = 흐름이 끊긴 씬** — 억지로 채우지 말고 대본을 고친다.

### I. 초면 청자 (STEP 1c — 문장 내부)
why는 작성자 시점이라 청자가 모르는 정보를 못 잡는다. 문장마다 **"이 문장만 들으면 무엇이 떠오르나"** 로 묻는다.

| 검사 | 질문 | 실패 시 |
|---|---|---|
| I-1 지시어 | "이/그 X"의 X가 직전 씬에 명사로 있나 | 대상을 직접 말한다 |
| I-2 종결 | 서술어로 끝나나(§5-1) | "…울산급." → "…우리 손으로 만든 배였습니다." |
| I-3 용어 | 처음 듣는 사람이 모를 말이 있나 | "배틀스타 5개" → "태평양에서 다섯 번을 싸운" |
| I-4 주어·목적어 | 누가/무엇을이 있나 | 되살린다. 40자가 모자라면 문장을 나눠 같은 씬에 |
| I-5 내부 모순 | CTA 주장이 본문 사실과 어긋나지 않나 | 사람이 본다(자동 불가) |

- `[PLAIN-1~4]`는 경고(휴리스틱). 끄지 말고 판단하고, 무시했으면 이유를 한 줄 남긴다.
- `[SUBJ]`: 문장 주어가 북한·중국·미국인데 소재가 한국 장비면 경고(대립 프레임에선 차단). 국적이 안 드러나는 컷을 쓰거나 주어를 우리 쪽으로 돌린다.
- `[ROOM]`: 길이 여유가 15초 이상인데 문장이 40자에 붙으면 경고 — 처방은 "문장을 나눠 같은 씬에 이어 쓰기".

**흐름 예시 (mil_004 K9)**

| 비트 | 대본 |
|---|---|
| HOOK | 자주포 원조 독일이 자기 자주포를 포기하기 시작했습니다. |
| TENSION | 그런데 정작 유럽 최전선 국가들은 한 자주포 앞에 줄을 섭니다. |
| TENSION | 폴란드가 3백 대를 넘겼고 루마니아도 곧바로 뒤를 따랐죠. |
| VALUE(reveal) | 이 자주포의 이름은 K9입니다. 한국이 만들었습니다. |
| PROOF | K9가 팔리는 이유는 단순합니다. 명령을 받고 30초 만에 쏘거든요. |
| PROOF | 게다가 쏘고 1분 안에 사라져서 혼자서 여러 대 몫을 합니다. |
| VALUE | 그 결과 세계 시장의 절반, 두 대 중 한 대가 K9입니다. |
| 착지 | 그래서 원조 독일마저 자국 물량을 한국에 기대야 할 판입니다. |
| CTA | 독일이 비운 그 자리를 이제 대한민국이 채웁니다. 대한민국을 응원합니다. |

## 11. 과장 검수 — 문장이 아니라 "배열이 만드는 명제"

**벽돌이 전부 진짜여도, 쌓아놓으면 없는 건물이 보일 수 있다.** mil_114: "미 공군이 홍해에서 사이드와인더로 자폭 무인기를 잡았다"(참) + "이 103발은 F-15K·KF-16·F-35A에 실린다"(참) + "이제 그 하늘을 103발이 채운다"(참) → 이어 들으면 "북한 드론이 오면 AIM-9X 103발로 잡는다"(거짓). facts에 "재고 보충용"·"잠정 승인"이 있었는데 무시됐다.

### 11-1. 청자 도출 명제 (STEP 1d, `[CLAIM]` 차단)
대본을 다 쓴 뒤 청자가 되어 **"다 듣고 나면 믿게 되는 것" 3~5개**를 scenes.json 최상위 `audience_takeaways`에 적고 각각 `fact_ids`를 단다. 근거가 비는 항목이 하나라도 있으면 그 인상을 만드는 문장(대개 CTA·병치된 사례 씬)을 고친다.

```json
"audience_takeaways": [
  {"claim":"미국이 AIM-9X 103발 판매를 잠정 승인했다 — 아직 계약 전이다","fact_ids":["f04","f05"]},
  {"claim":"이 103발은 드론 요격 전용이 아니라 공대공 재고 보충분이다","fact_ids":["f06"]}
]
```

### 11-2. 제한 준수 (`[SCOPE]` 차단)
§7의 `scope_ok`. 예: `"scope_ok":"'늘어납니다'로 미래형을 써서 도입 완료를 주장하지 않는다. 103발이 드론을 잡는다는 인과도 만들지 않는다"`.

### 11-3. 교환비 (`[XCHG]` 경고)
고가 유도무기로 저가 표적(드론)을 잡는 서사면 1발 단가·표적 원가·실제 운용 교리를 facts에 넣고 확인한다. 특수 사례가 상시 수단은 아니다. 교환비는 오히려 아이러니 재료다:
- ✅ "미군도 홍해에서 이걸로 드론을 잡아봤습니다. 다만 한 발이 16억입니다. 드론용이 아니라 전투기 재고죠."

`[THESIS]`(경고): 인용이 `source_thesis`와 반대 방향이면 짚는다.

## 12. 대립 서사 (엔진 F) 상세

대립의 재미는 상대가 나빠서가 아니라 **판이 팽팽해서** 나온다.

### 12-0. 순서: 팩트 → 대립 정찰 → 방향 선택 → 대본
상대의 수는 따로 찾지 않으면 facts.json에 안 들어온다(최근 10편 중 6편이 상대국 팩트 0건 → F 자동 탈락).
- **STEP 0-2 대립 정찰**: 산출물 `_work/<run>/conflict_scout.json`. (`[SCOUT]` 경고)
- **STEP 0-3 방향 선택(멈춤)**: Claude가 정하지 않고 **Walter가 고른다.** 선택지에 **항상 "대립 없음"** 포함 — 억지 대립이 과장(§11)의 재발 경로다. (`[ENGINE]` 경고)

### 12-1. 대립축 `conflict_axis` (네 칸이 다 팩트가 아니면 F가 아니다)

```json
"engine": {"primary": "F", "secondary": "A"},
"frame": "contest",
"conflict_axis": {
  "type": "threat",
  "them": "중국",
  "their_move": "앤틸로프 암초에 3,000m 활주로로 보이는 굴착 (위성사진)",
  "stake": "필리핀 코앞 바다의 하늘 — 통째로 중국 전투기 사정권",
  "our_move": "필리핀이 FA-50 12대 추가 계약 → 24대 체제",
  "fact_ids": ["f02", "f05", "f07"]
}
```

| 칸 | 적을 것 | 흔한 실패 |
|---|---|---|
| `them` | 상대(국가·기업) | "서방"·"강대국"처럼 뭉뚱그리기 |
| `their_move` | 상대가 **실제로 한 일** | 마음속 의도("견제하려고") |
| `stake` | 걸려 있는 것 | 비우면 뉴스 두 개 나열 |
| `our_move` | 우리가 둔 수 | **시간 순서 역전** — 날짜를 facts에 넣고 대조 |

### 12-1b. 대립 유형 `type` (단일 소스 `conflict_presets.json`)

| type | 골격 | 최대 사고 지점 |
|---|---|---|
| `threat` 위협→응수 | 상대의 배치·시험 → 뚫린 공백 → 우리의 배치·도입 → 판의 변화 | `[MOTIVE]`가 가장 잘 난다. 의도 말고 행동만 |
| `market` 시장 쟁탈 | 발주국 조건 → 경쟁사가 못 준 것 → 우리가 준 것 → 계약 | 스펙 비교표로 끝나면 C다 |
| `tech` 기술 추격 | 상대가 가졌던 것 → 우리가 못 가진 이유 → 확보한 수 → 남은 격차 | "이겼다"로 닫으면 과장. 남은 격차 한 줄이 신뢰를 올린다 |
| `alliance` 종속 탈피 | 동맹이 쥐던 것 → 못 했던 것 → 확보한 수 → 관계 변화 | 비하 없이 성립하는 가장 안전한 유형. 동맹을 악당으로 만들지 말 것 |

### 12-2. 씬 배열 `side`
정보 씬에 `"side": "them" | "us" | "board"`. **정보 구간에서 `them` 3연속 금지**(사이에 board·us). `them`이 0이면 대립이 아니고, `us`가 0이면 상대국 홍보다. `[CONTEST]` 경고.

### 12-3. 상대의 마음을 쓰지 마라
| ✗ 심리 추정 | ✅ 관측된 행동 |
|---|---|
| "중국이 긴장하고 있습니다" | "중국 국방부가 이례적으로 논평을 냈습니다"(보도 팩트) |
| "북한이 두려워합니다" | "북한이 그 주에 요격 훈련을 공개했습니다" |

보도·성명·논평이 팩트로 있으면 써도 되고, 그 fact_id를 씬에 단다. `[MOTIVE]` 경고.

### 12-4. 화면
- weapon 슬러그는 국적을 못 가른다. `side:"them"` 씬에 우리 장비가 깔리면 대립축이 뒤집힌다(`[SUBJ]` 차단). hint에 국적 토큰, 국적이 안 드러나는 컷, 또는 `concept` 슬러그.
- 상대국 무기를 멋있게 보여주는 컷은 피한다(주인공이 바뀐다).

### 12-5. CTA — 병렬 대구로 판의 변화를 닫는다
- ✅ "중국이 섬을 하나 만들 때마다, 필리핀 하늘엔 한국 전투기가 늘어납니다." (mil_129)
- ✅ "좋은 대포를 설계하는 나라는 많습니다. 제때, 많이 만들어 내는 나라는 드뭅니다." (mil_130)
- ✗ "이제 중국은 아무것도 못 합니다" (없는 결론 + 비하)

### 12-6. 중국 축 체크리스트
1. **중국 관련 수치·교전 주장은 한국 커뮤니티·유튜브를 출처로 쓰지 않는다.** "K9이 중국산 자주포 4대 격파"류 서사는 mil_110 교차검증에서 6개 주장이 전부 붕괴했다.
2. **`conflict_axis.china_crosscheck` 의무** — 중국 측 발표(국방부 정례브리핑·신화)를 한 번 직접 확인해 한 줄 적는다. `[CONTEST]` 차단 조건(대상국은 `conflict_presets.json`).
3. **화면이 거의 없다** — `side:"them"` 씬은 거의 전부 `ai_first`. 방향을 고르는 시점에 "AI 컷 N개"를 알린다(`conflict_scout --table`). AI 프롬프트에 제식명(SH-15·PCL-181) 금지 — 형상 6요소로 서술.
4. **톤** — 중국 축에서 `[HOSTILE]`이 가장 잘 터진다. 숫자와 일정으로만 대비한다.

## 13. 화면 소재 규칙

- **소재 비율**: 영상 80% 이상, 사진 최대 2씬(10씬 기준, Ken Burns 자동). 사진은 문맥이 정확히 맞을 때만.
- **씬별 소재 문맥화**: footage.phrases를 씬 내용에 맞게 다르게. 전 씬 동일 phrases 금지.
- **자료화면(타 무기·타국 b-roll)**: 특정 무기를 지칭하지 않는 구간에서만. 씬에 `caption_note`("자료화면 · 미군 시험발사") 의무. 풀: broll_intercept·broll_c17·broll_radar.
- **AI 생성 컷**: 실촬영 원본이 존재하지 않는 장면에만, 편당 1~2컷(대립 서사 `them` 씬은 예외 — §12-6).
  - 흐름: Claude가 Veo 프롬프트 작성 → Walter가 Google Flow에서 생성 → `python3 ai_intake_v1.0.py --run-id <run> --scene N --file <mp4> --desc <슬러그>`
  - caption_note "AI 연출 화면"(도구 자동) + caption.txt AI 고지 1줄.
  - 템플릿: "[시간대·장소], [피사체+동작], [카메라 워크], cinematic realistic, vertical 9:16, no text, no watermark" — 실무기 형상 특정 금지, 국기·마킹 금지.

- [ ] 루프 엔딩이 훅과 이어지되 정서로 회수(없는 인과 없음)

**문장 (§5)**
- [ ] 명사 종결 조각은 편당 1회 이하, 다음 문장은 완결 문장
- [ ] 한 문장에 쉼표 1개 이하, 주어·첫 접속사 뒤 쉼표 없음
- [ ] 같은 어미 4연속 없음, "~거든요"는 이유가 있는 자리에만
- [ ] 번역투(~를 통해·~에 의해·되어지다) 없음
- [ ] 탈것에 "짓다" 없음, `[pause]` 태그 0개
- [ ] 군사용어마다 3초 번역, 수치마다 원수치→환산 순서
- [ ] 초등 5학년이 못 알아들을 문장 없음

**길이 (§3-2)**
- [ ] 소리 내 읽어 자연스럽다. 55~75초 목표, 90초 허용, 50초 미만 차단
- [ ] 문장 ≤40자·씬 ≤70자. 모자라면 깎지 않고 나눠서 같은 씬에

**절차 (§9)**
- [ ] 씬 text가 초안 `## 산문 (정본)` 문장 그대로(`[REWRITE]`·`[REWRITE-NEW]`)
- [ ] 초안의 절이 씬에서 조용히 빠지지 않았다(`[REWRITE-CUT]`). 고칠 게 있으면 초안을 고치고 다시 나눴다

**흐름 (§10)**
- [ ] 정보 씬마다 `rel`을 적었고, 붙인 커넥터가 `rel`과 맞다. `rel:"없음"` 2회 이하
- [ ] 정보 씬마다 "이 문장, 왜?"의 답이 바로 앞 씬에 있다(G). why가 자연스럽게 써진다
- [ ] 초면 청자 I-1~I-5 통과
- [ ] 씬 1→N을 한 문단처럼 이어 읽어 걸리는 데가 없다

**사실·과장 (§7·§11)**
- [ ] 전 문장이 facts.json에 근거가 있다. 외국어 출처는 `claim_ko`에서 문장을 가져왔다
- [ ] `audience_takeaways` 3~5개에 전부 fact_ids가 붙는다
- [ ] `scope`·`caveat` 팩트를 인용한 씬마다 `scope_ok`
- [ ] 고가 무기 vs 저가 표적 서사면 교환비 확인
- [ ] 상대의 마음을 서술한 문장마다 보도 근거 fact
- [ ] 금지 목록 9항 위반 없음
